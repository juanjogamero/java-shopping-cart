EL PROYECTO REAL

Java, sin complicaciones.

El código de producción de esta práctica está en src/main/java/. La lógica utiliza números decimales exactos y valida los datos antes de aceptar un producto.

Main.java · ejemplo de uso
Carrito carrito = new Carrito();
carrito.agregar(new Elemento(
    "Tarjeta SD 64 GB", new BigDecimal("19.95"), 2
));
carrito.agregar(new Elemento(
    "Canon EOS 2000D", new BigDecimal("449.00"), 1
));

System.out.println(carrito.importeTotal()); // 488.90
carrito.actualizarCantidad("Tarjeta SD 64 GB", 3);
carrito.eliminar("Canon EOS 2000D");
DETALLES DE IMPLEMENTACIÓN

Preparado para aprender y ampliar.

01

Precisión monetaria

BigDecimal evita las imprecisiones habituales de los cálculos de dinero con tipos de coma flotante.

02

Reglas claras

La lógica valida cantidades, evita precios negativos y agrupa elementos repetidos por nombre y precio.

03

Probado en GitHub

Una suite de pruebas comprueba totales, agrupación, modificación, eliminación y entradas inválidas.
